Điểm nhấn để giao diện "cao cấp"

Để WinForms nhìn gần với ứng dụng web hiện đại, nên thống nhất các nguyên tắc sau:

Không dùng viền Windows mặc định cho Button, TextBox, DataGridView.
Chỉ sử dụng 4–5 màu chủ đạo trên toàn hệ thống.
Mọi Button, Card, TextBox đều có bo góc đồng nhất.
Sidebar luôn có icon và trạng thái Active rõ ràng.
Dashboard dùng Card + biểu đồ + KPI, tránh chỉ hiển thị bảng dữ liệu.
Dùng icon SVG hoặc FontAwesome để giao diện sắc nét ở mọi độ phân giải.
Hỗ trợ Dark/Light Mode bằng cách đổi Theme thay vì chỉnh từng control.
